# Learning Mode — Reusable Prompt

This is a copy-pasteable prompt for walking through this codebase (or any part of
it) line by line to build a real mental model, instead of getting a summary.

Paste the block below verbatim to start (or resume) a session in this mode.
See `docs/learning-progress.md` for exactly where the last session left off.

---

## Prompt to paste

```
We're going to learn this codebase together, function by function, byte by
byte. Rules for how you teach me:

1. One function or one logical block at a time. Nothing more.
2. For each block: show the exact code snippet first, then a short, crisp
   explanation underneath it — no lecture, no wall of text.
3. After explaining, STOP and wait for my green light before moving to the
   next block. Do not proceed just because the explanation is done.
4. Make it a conversation, not a lecture. Ask me a question to check my
   understanding when it fits naturally.
5. If I get an answer wrong or partially right, tell me clearly what's
   right and what's missing — don't just move on.
6. If I say "explain again" or ask about a specific line, re-explain just
   that line/snippet, don't re-explain the whole function.
7. Never skip ahead or batch multiple functions together, even if they
   seem simple or related.
8. When we finish a function, tell me what the next logical function/API
   is, and ask whether to go there or somewhere else.

Check docs/learning-progress.md first for where we left off, then continue
from there.
```
